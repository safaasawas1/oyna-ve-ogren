# لَعِب وتَعَلَّم | Oyna ve Öğren

موقع ألعاب تعليمية بسيط للأطفال بالعربية والتركية، مبني باستخدام HTML وCSS وJavaScript فقط.

## تشغيل الموقع على جهازك
1. فكّي ضغط الملف.
2. افتحي مجلد `oyna_ve_ogren`.
3. افتحي `index.html` بمتصفح مثل Chrome.

لا يحتاج الموقع إلى تثبيت مكتبات أو إنترنت حتى يعمل محلياً.

## نشر مجاني باستخدام GitHub Pages
1. أنشئي حساباً على https://github.com إذا لم يكن لديك حساب.
2. أنشئي مستودعاً جديداً (New repository)، مثلاً باسم `oyna-ve-ogren`.
3. ارفعي ملف `index.html` إلى المستودع.
4. افتحي Settings ثم Pages.
5. تحت Build and deployment اختاري Deploy from a branch.
6. اختاري الفرع `main` والمجلد `/ (root)` ثم Save.
7. انتظري قليلاً؛ سيظهر رابط الموقع في صفحة Pages.

## ملاحظات
- هذه نسخة أولية للتجربة وليست منتجاً نهائياً.
- النقاط تُحفظ خلال جلسة المتصفح فقط؛ لا توجد قاعدة بيانات.
- قبل النشر العام، اختبري الأسئلة والترجمة على الهاتف والكمبيوتر.
- لا تجمعي بيانات شخصية للأطفال.
